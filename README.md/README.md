
# Retail Sales Analysis

## Project Overview
This project analyzes retail sales data using Microsoft Excel and MySQL to identify sales trends and business insights.

## Tools Used
- Microsoft Excel
- MySQL
- SQL

## Analysis Performed
- Total sales, orders, and customers
- Sales by region and category
- Sales by sub-category
- Monthly sales trends
- Top-selling products and customers
- Data quality checks

## Key Findings
- The West region recorded the highest sales.
- The South region recorded the lowest sales.
- Chairs and Phones were among the top-selling sub-categories.

## Project Files
- `data/raw/` — Original dataset
- `data/cleaned/` — Cleaned dataset, if applicable
- `excel/` — Excel analysis and dashboard
- `sql/` — SQL query files
- `report/` — Project findings and report
